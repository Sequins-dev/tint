# General runtime A7 · outlined numeric kernels, hoisted array data pointers, inline ordinary-object checks, and sampled megamorphic IC eviction · Darwin arm64

Step A7 of PR #12 on top of the A6 head (`bdde6ac9e`): preserve outlined `__tint_spec_loop_*` helper names through module linking so inlining keeps numeric loop kernels outlined and AArch64 scalar codegen enables intraprocedural `provenWordFacts` / `provenIntegerSlots` and hoists the top two loop-weighted immutable `Float64Array` parameter data pointers into `x14`/`x15`; outline proven-unchecked inner loops (e.g. `lin_solve`, `project`, `set_bnd`) and non-proven 2D numeric loops (`advect`-like bilinear stencils with epilogue writeback buffers and exact general-loop deopt tails); inline `isOrdinaryObject` by stripping redundant non-parameter slots in `bindRecordOperation`, propagate known object tags across fused property accesses (`knownObjectTagAccesses`), add ordinary-object fast paths to `new` return checks, sloppy prologues, `==`/`!=`, and `!htmlDDAObjects` truthiness (`ToBoolean`), inline global cell writes and `new Array(...)` construction, add lazy zero-parameter forwarding scopes for `this.initialize.apply(this, arguments)`, and switch megamorphic IC inline eviction to 1-in-64 sampling with duplicate-shape guards. Base `bdde6ac9e`; head `eee5848ad` (plus test-host capability alignment in `5fb603af2`, leaving `packages/` unchanged). Apple M5 Max, Node 26.13.1.

On Octane (18 paired rounds, 9/18 rounds ≥75% host idle, 79.5% base / 77.6% A7 median idle), **NavierStokes drops another −50.09%** (`6.504 → 3.241 ms/op`, **`1.6×` Node**; ≥75%-idle `6.233 → 3.074 ms/op`, `−51.59%`, `1.6×` Node), **RayTrace drops −13.70%** (`8.089 → 7.072 ms/op`, `12.1×` Node; ≥75%-idle `7.862 → 6.780 ms/op`, `−14.22%`, `13.0×` Node), **DeltaBlue improves −3.59%** paired per-round (`2.455 → 2.460 ms/op` overall median, `36.3×` Node; ≥75%-idle `2.365 → 2.305 ms/op`, `−5.38%`, `35.3×` Node), and **Richards is −1.20%** (`0.976 → 0.997 ms/op` overall, ≥75%-idle `0.946 → 0.922 ms/op`, `−1.79%`, `20.1×` Node). On the generality suite (18 paired rounds, 15/18 ≥75% idle), A7 recovers the A6 regressions: **`receivers8` −13.06%** (`52.308 → 45.285 ns`, `−6.67 ns`), **`concatenateStrings` −5.75%** (`14.583 → 13.306 ns`), and **`mutableCapture` −5.09%** (`14.627 → 13.824 ns`), with `mixedCall` (`−2.40%`, `−3.29%` ≥75%-idle) and `buildString` (`−1.72%`) trending down. On the elements and builtins suite (18 paired rounds, 15/18 ≥75% idle), **`numberElementWrite` drops −13.26%** (`1.633 → 1.412 ns`, `0.8×` Node) and **`objectElementRead` drops −4.47%** (`10.966 → 10.343 ns`), keeping all three numeric element kernels and `objectLiteral` ahead of Node (`0.7×` to `0.9×` Node). On the call and loop kernels (20 paired rounds, 18/20 ≥75% idle), **`stringEquality` drops −13.03%** (`0.955 → 0.832 ns`, `0.4×` Node) and **`rest` drops −1.98%** (`0.821 → 0.806 ns`, `0.1×` Node), with all eight kernels remaining ahead of Node (`0.03×` to `0.8×` Node). On `neon` warm-call traces, `make(v)` (`new Box(v)`) drops **−7 instructions** (`466 → 459`, `−1.5%`) from inlining `isOrdinaryObject`. Frozen v7 `--runtime-tree` produces bit-for-bit identical `__text`, `__eh_frame`, `__unwind_info`, and `__data` Mach-O sections. Both Darwin arm64 `stage1 == stage2` and native `stage1 --target linux-x86_64` cross-emission reproduce their stage-1 images byte for byte under LLDB.

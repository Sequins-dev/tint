# Generational Workers on arm64 (paired A/B against copying Workers)

24 November 2026. Paired, rotated 15-round comparison of `perf/generational-workers`
(`531fe0887`, lazy collector pool) against `main` (`b5ff7e6e4`, copying-collector
Workers on arm64), plus the preliminary warm-pool measurement (`70a8058ec` vs `8b59d2b6a`)
that motivated keeping collector-pool startup lazy.

**Protocol.**

- Host: Apple M5 Max (18 cores), macOS arm64, `TZ=UTC`.
- Each set ran 15 paired, rotated rounds under `tools/gate/with-lock.sh both`.
- Every native run launched under LLDB, asserting stopped-at-entry and exit status 42.
- Kernels report steady-state mean (ms/iteration) and cold iteration; transport reports
  median us/op; wall time is seconds per run. Cells are median (IQR); ratios are paired
  within each round.

**No-Worker byte identity.** `tools/build-typed-bigint-fixture.ts` produces byte-identical
images on `main` (`b5ff7e6e4`) and `perf/generational-workers` (`531fe0887`):
`031356fcf9934fcb5478a6e62ec9c21e8e82d030b5978e47b38d4ad1de5bccc6`.

# Octane cost breakdown on macOS arm64

On the selected Tint build, property operations account for 42% of DeltaBlue and 61% of RayTrace main-thread samples. RayTrace pays for its constructor forwarding twice in the runtime: dispatch and argument handling, then descriptor construction for the `arguments` object. NavierStokes instead spends most of its time in generated numerical loops and computed element access. Richards spends more samples on spec helpers than on named property operations.

The sampled image is byte-for-byte the untyped candidate from the paired trials, SHA-256 `a57d6ccacc20c68d4adb9576e157ae9269126c6646e51d9b13bd525cb3f51d97`. The profiles are three fresh launches through `tools/gate/with-lock.sh both` with pprofessor attached to the main thread at a requested 997 Hz. LLDB confirmed a stop at entry, delimited each timed window at the driver's native clock call and verified inferior exit 42. The three runs returned all expected checksums. Logs and twelve compressed pprof files are retained locally under `/private/tmp/tint-octane-cost.Zp31rt`, with hashes and observed elapsed times in the companion JSON.

The tables count pprof's `samples` weights. Grouping uses the sampled leaf, then the nearest identifiable runtime owner for shared support code such as list traversal and value projection. Attribution stops at the generated guest function so its body does not count as invocation overhead. For runtime sites with source locations, Mach-O addresses are normalized for ASLR and resolved against the exact image's DWARF. The successful cache-return instruction ranges were checked in the disassembly. Host clock-boundary samples are retained under Other. Profiler attach and debugger stops affect coverage near those boundaries. The numbers measure the observed main-thread sample distribution. They do not measure operation frequencies, allocated bytes, elapsed time in every category, or Node's time distribution.

## Structural causes and V8 comparison

Tint currently constructs ordinary receivers with the same wide object record and a property map. As named properties are added, it creates or updates dictionary descriptors. A cached lookup can build a second layout by walking that dictionary and installing a key list and descriptor-cell list. It can share a matching shape and reuse the site or global cache, but different instances still own their backing maps and layouts. This gives Tint guarded shapes without canonical shape transitions at the stores that create the fields. A primary inline case checks the receiver layout and, on an inherited access, the direct holder. The runtime stub can guard up to three prototype links. Longer, exotic and ineligible chains go through ordinary lookup. In this image the specialized runtime lookup at 0x1020efc60 reserves 512 bytes of stack space in addition to the frame/link register pair and saves multiple registers even on a successful cache probe. During a refill, the stub searches the available shaped key lists, with deep fallback to generic property lookup. Prototype methods can hit these cached paths, but inherited runtime hits still load and guard links and then read the descriptor. [Tint object allocation and layout](https://github.com/Sequins-dev/tint/blob/84873b2b78e370983969e81b89c896e69c3af5b9/packages/js-runtime/src/objects/operations.ts#L526-L559), [Tint cache and generic lookup](https://github.com/Sequins-dev/tint/blob/84873b2b78e370983969e81b89c896e69c3af5b9/packages/js-runtime/src/objects/operations.ts#L1064-L1278), [Tint generated property case](https://github.com/Sequins-dev/tint/blob/84873b2b78e370983969e81b89c896e69c3af5b9/packages/js-engine/src/lowering/index.ts#L2764-L2850)

V8's Maps own shared descriptors and search transitions on field addition. A field handler chooses an in-object offset or an offset in the property array. Dictionary storage is a fallback. Prototype handlers can validate a chain via one validity cell and then use a cached holder. Megamorphic load probes compare map and name in shared tables. A fast `new` path allocates using the target's initial Map, using an empty property array for a fast map. The optimizing tier can emit the initialization directly and scalar-replace eligible non-escaping allocations. This comparison uses the V8 source shipped with the Node release. The profiles cover Tint, so the V8 mechanisms describe what is available at these sites. [Map transitions](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/objects/map.cc#L2056-L2105), [field IC](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/ic/accessor-assembler.cc#L418-L445), [prototype validity](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/ic/accessor-assembler.cc#L1163-L1183), [stub cache](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/ic/accessor-assembler.cc#L3193-L3256), [fast constructor allocation](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/builtins/builtins-constructor-gen.cc#L337-L374), [compiler object allocation](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/compiler/js-create-lowering.cc#L115-L145), [escape analysis reducer](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/compiler/escape-analysis-reducer.cc#L75-L135)

Tint has native positional entries for eligible same-Script ordinary calls. They can still run source-frame and execution-name bookkeeping. Generic ordinary construction always lowers `new` to argument-list construction plus `constructObjectValue`. Its runtime checks constructibility, enters the execution context, allocates a receiver via the new target's prototype, invokes the source wrapper and checks the returned value. The generic ordinary-call dispatcher also accepts a list and wraps the result. On V8's ARM64 ordinary JS call path, `x0` carries the actual argument count, `x1` the function, `x3` the new target and `cp` the callee context. Receiver and actual arguments are on the stack. The invocation loads an entry through the JS dispatch table. Equal and over-applied arities bypass padding. For under-application the ARM64 prologue can move the argument area and fill missing slots with undefined within the same activation. V8 has no separate arguments-adaptor frame on this path. [Tint call and construct](https://github.com/Sequins-dev/tint/blob/84873b2b78e370983969e81b89c896e69c3af5b9/packages/js-runtime/src/objects/call.ts#L9-L65), [Tint constructor wrapper](https://github.com/Sequins-dev/tint/blob/84873b2b78e370983969e81b89c896e69c3af5b9/packages/js-runtime/src/objects/functions.ts#L522-L604), [Tint new lowering](https://github.com/Sequins-dev/tint/blob/84873b2b78e370983969e81b89c896e69c3af5b9/packages/js-engine/src/lowering/index.ts#L7438-L7445), [V8 ARM64 JS call](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/builtins/arm64/builtins-arm64.cc#L2875-L2968), [V8 arity and dispatch](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/codegen/arm64/macro-assembler-arm64.cc#L2692-L2769), [V8 dispatch entry](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/codegen/arm64/macro-assembler-arm64.cc#L2853-L2896)

### Richards

1. **Other (50.7%).** The generated scheduler, handler and task-block code accounts for 462 samples. `Scheduler.schedule` and `TaskControlBlock.isHeldOrSuspended` together account for 148 of these. A scheduling iteration repeatedly loads fields and makes short calls, including polymorphic task calls. Inlined guards and dispatch can be part of these leaves. Another 128 samples are collection work with no clear caller. V8 can turn stable field and method accesses into guarded loads and inline short callees that meet the call-target checks. This can remove work inside the generated loop along with helper calls. [Octane scheduling loop](https://github.com/chromium/octane/blob/570ad1ccfe86e3eecba0636c8f932ac08edec517/richards.js#L179-L200), [task-block hot methods](https://github.com/chromium/octane/blob/570ad1ccfe86e3eecba0636c8f932ac08edec517/richards.js#L309-L354), [V8 property specialization](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/compiler/js-native-context-specialization.cc#L3067-L3120)
2. **Spec machinery (22.3%).** `looselyEqual` accounts for 131 samples (10.7% of the program). Conditions such as `this.currentTcb != null` and equality checks on task state still reach the full abstraction with tag projections and coercion decisions. Maglev uses feedback to distinguish signed-small, number and receiver-or-nullish comparisons and emits operations appropriate to guarded input types. An AOT nullish arm must preserve the HTMLDDA case where the host exposes it. [Tint loose equality](https://github.com/Sequins-dev/tint/blob/84873b2b78e370983969e81b89c896e69c3af5b9/packages/js-runtime/src/objects/equality.ts#L19-L121), [Maglev compare lowering](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/maglev/maglev-graph-builder.cc#L2871-L3048)
3. **Property (17.6%).** Reads account for 177 of the 216 samples. The dominant identified work is list leaf search, cache lookup and cache-cell probes. It recurs even in a scheduler working with long-lived instances. The constructors populate the normal dictionary, and an offset in a cached layout still requires a descriptor-cell load. V8's in-object field handler maps the shared constructor shape to the field directly. [Octane task-block constructor](https://github.com/chromium/octane/blob/570ad1ccfe86e3eecba0636c8f932ac08edec517/richards.js#L260-L278), [V8 field handler](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/ic/accessor-assembler.cc#L418-L445)

### DeltaBlue

1. **Property (42.1%).** Repeated reads and writes on variables and constraints include inherited methods such as `Plan.execute` calling `c.execute()` across distinct constraint types. There are 210 identified refill/fallback samples and 262 dictionary/layout-build samples. Those are independent views and overlap. The bounded prototype stub can avoid complete ordinary dispatch but still loads per-instance layouts, searches on a miss and reads a descriptor from a list. V8's mapped objects and validity-checked polymorphic handlers give stable offsets for the graph fields and holder-based access to inherited methods. [Octane constraint setup and inheritance](https://github.com/chromium/octane/blob/570ad1ccfe86e3eecba0636c8f932ac08edec517/deltablue.js#L214-L275), [plan execution](https://github.com/chromium/octane/blob/570ad1ccfe86e3eecba0636c8f932ac08edec517/deltablue.js#L760-L786), [V8 polymorphic IC update](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/ic/ic.cc#L632-L692)
2. **Other (33.7%).** 477 samples are in generated JS, led by `Plan.execute` and input and output selectors such as `BinaryConstraint.output`. The guest bodies comprise small branches, object accesses and method calls. Ordered collections add layers of `size()`, `at()` and indexing, and 127 collection-helper samples have unresolved owners. V8 can combine fixed array-element access with guarded field loads and remove some tiny method boundaries in optimized code. The profile cannot separate those opportunities into exact per-instruction shares. [Octane collection and accessors](https://github.com/chromium/octane/blob/570ad1ccfe86e3eecba0636c8f932ac08edec517/deltablue.js#L59-L83), [input and output selectors](https://github.com/chromium/octane/blob/570ad1ccfe86e3eecba0636c8f932ac08edec517/deltablue.js#L407-L415), [Maglev array element lowering](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/maglev/maglev-graph-builder.cc#L6504-L6536)
3. **Calls (11.8%).** 226 of 255 call samples are frame and receiver work, and at least 121 show a direct positional path. Entering the native JS body bypasses some generic dispatch but can still adjust the sloppy receiver, maintain the execution-name and visible-caller chains, and clear retained argument fields on exit. A uniform native frame layout can represent the ordinary call state as part of the activation, with observation handled when requested. V8's standard frame and function-context convention leaves ordinary calling state on its native call path, including sloppy receiver conversion when required. [Tint source frames](https://github.com/Sequins-dev/tint/blob/84873b2b78e370983969e81b89c896e69c3af5b9/packages/js-runtime/src/objects/jobs.ts#L182-L258), [Tint execution names](https://github.com/Sequins-dev/tint/blob/84873b2b78e370983969e81b89c896e69c3af5b9/packages/js-runtime/src/objects/jobs.ts#L306-L325), [V8 ARM64 call](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/builtins/arm64/builtins-arm64.cc#L2875-L2968)

### NavierStokes

1. **Other (58.7%).** The emitted `lin_solve` alone accounts for 329 samples, or 37.3% of the program. Its inner loops operate on general JS arrays allocated by `FluidField.reset`. The image already has specialized reads for eligible packed numeric storage, so the residual includes guest arithmetic, tag/bounds checks and inlined element code. The available maps do not partition the guest machine code into exact cycles for those components. V8's Maglev has distinct double-element loads and stores and can propagate floating-point intermediates across these operations with guards. [Octane solver](https://github.com/chromium/octane/blob/570ad1ccfe86e3eecba0636c8f932ac08edec517/navier-stokes.js#L152-L185), [Tint generated indexed cases](https://github.com/Sequins-dev/tint/blob/84873b2b78e370983969e81b89c896e69c3af5b9/packages/js-engine/src/lowering/index.ts#L2950-L3062), [Maglev element specialization](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/maglev/maglev-graph-builder.cc#L6504-L6536)
2. **Property (27.2%).** 205 of 240 samples are writes, including 64 in `writeArrayElement` and 60 in `writeObjectValuePropertyKey`. Indexed stores mostly enter a helper, project the base, check the storage kind and bounds, and update the backing store. The numeric index avoids stringification on the eligible overwrite path. The generic fallback can still convert it, accounting for the additional 35 Numbers samples. Moving numbered entries to direct array element operations matters here more than speeding up named-field ICs. V8 lowers guarded packed double stores to element-address and floating-point operations and keeps slower array transitions outside that path. [Tint computed store](https://github.com/Sequins-dev/tint/blob/84873b2b78e370983969e81b89c896e69c3af5b9/packages/js-runtime/src/objects/coercion.ts#L123-L202), [Tint array element storage](https://github.com/Sequins-dev/tint/blob/84873b2b78e370983969e81b89c896e69c3af5b9/packages/js-runtime/src/objects/array-elements.ts#L70-L113), [V8 indexed stores](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/maglev/maglev-graph-builder.cc#L6377-L6536)

There is no identified environment or realm hotspot in this program. ### RayTrace

1. **Property (60.8%).** Repeated construction and mutation of `Color`, `Vector` and `IntersectionInfo` pay for descriptor entries and lazy cached layouts on each receiver. Dictionary/layout build accounts for 2,386 samples, including hash/map work. 1,722 property samples are identified refill or generic fallback. Separately, 1,288 property samples occur under `arguments` materialization. Fast Maps and pre-sized in-object slots would make object initialization and repeated field access cheaper. Removing avoidable argument materialization attacks a different portion of these samples. [Octane Color initialization](https://github.com/chromium/octane/blob/570ad1ccfe86e3eecba0636c8f932ac08edec517/raytrace.js#L77-L105), [IntersectionInfo initialization](https://github.com/chromium/octane/blob/570ad1ccfe86e3eecba0636c8f932ac08edec517/raytrace.js#L520-L537), [V8 initial-map allocation](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/builtins/builtins-constructor-gen.cc#L337-L374)
2. **Other (17.3%).** There are 825 samples in emitted JS, led by the `Class.create` trampoline and `rayTrace`. `testIntersection` also allocates small records while looping over a mixed shape list and calls each shape's `intersect` method. Even with cheaper field handlers, the emitted arithmetic, receiver checks and allocations inside nested calls need compiler visibility. V8's optimized object creation and escape analysis provide mechanisms to collapse some of that work where the target and object lifetime are provable. [Octane intersection and lighting](https://github.com/chromium/octane/blob/570ad1ccfe86e3eecba0636c8f932ac08edec517/raytrace.js#L677-L738), [V8 creation lowering](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/compiler/js-create-lowering.cc#L115-L145), [V8 escape analysis reducer](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/compiler/escape-analysis-reducer.cc#L75-L135)
3. **Calls (10.8%).** The constructor helper runs `this.initialize.apply(this, arguments)` through generic `new`, argument-object construction, reading the argument object's properties back into an actuals list, and another dispatch. An ordinary direct ABI alone cannot skip an observable `arguments` value here. It needs guarded forwarding when the observed value is the builtin `apply`, the argument state can be forwarded, and no intervening operation has made the object observable or changed the indexed argument semantics. Maglev recognizes the builtin and has a reduction for eligible arguments-object calls, with a generic fallback. [Octane constructor trampoline](https://github.com/chromium/octane/blob/570ad1ccfe86e3eecba0636c8f932ac08edec517/raytrace.js#L33-L39), [Tint argument descriptors](https://github.com/Sequins-dev/tint/blob/84873b2b78e370983969e81b89c896e69c3af5b9/packages/js-runtime/src/objects/arguments.ts#L41-L119), [Maglev apply reduction](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/maglev/maglev-graph-builder.cc#L12066-L12101), [Maglev argument forwarding](https://github.com/nodejs/node/blob/e9c277643b0249c50f6e6de5413be8a88ea11b6a/deps/v8/src/maglev/maglev-graph-builder.cc#L12210-L12286)

The ranked response to these costs is in the [runtime re-architecture proposal](../design-general-runtime-rearchitecture.md).
